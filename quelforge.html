01 / quelforge

Backup e empacotamento com um clique

O Quelforge é a ferramenta oficial de backup e criação de pacotes do Quieux Linux, instalável via QUEL. Ele verifica o estado do sistema, salva snapshots incrementais e monta seus próprios pacotes .quel, tudo pela interface gráfica.

Como instalar Documentação
02 / sobre a ferramenta

Sobre o Quelforge

O Quelforge usa a mesma base do QUEL, squashfs e yad, para gerar snapshots do sistema com hash de cada arquivo. Isso permite saber exatamente o que mudou desde a última verificação. A partir disso, dá pra salvar backups incrementais ou empacotar só os arquivos alterados como um novo programa .quel, pronto para instalar em outra máquina.

03 / funções

O que o Quelforge faz

Verificar Sistema

Cria uma base com hash de todos os arquivos do sistema

Salvar Sistema

Empacota só o que mudou desde a última verificação

Restaurar Sistema

Restaura um backup .quel, sobrescrevendo o necessário

Criar Pacote

Monta um pacote .quel com nome, versão e descrição

Verificar Nix

Cria uma base com hash de todos os arquivos da pasta do Nix

Criar Quel com Nix

Empacota os arquivos novos do Nix desde a última verificação

04 / como funciona

Como funciona

1Verificar Sistema

Varre as pastas do sistema, calcula o hash SHA-256 de cada arquivo e grava essa lista como base em /quel/quelforge/system.txt. É o ponto de partida: sem essa base, nenhuma outra função funciona.

2Salvar Sistema

Refaz a varredura e compara com a base salva, isolando só os arquivos novos ou com hash diferente (arquivos de cache/temporários são ignorados). Esses arquivos são compactados em squashfs mantendo pastas e permissões originais, e salvos em /quel/quelforge/saves/ com data e hora do backup.

3Restaurar Sistema

Você escolhe um arquivo .quel gerado pelo Quelforge e ele é extraído direto na raiz do sistema, sobrescrevendo o que for necessário para voltar ao estado daquele backup.

4Criar Pacote

Usa a mesma comparação do Salvar Sistema, mas organiza o resultado como um pacote QUEL de verdade. Você informa nome, versão e descrição do programa, e o Quelforge monta as pastas info/ e quel/ exigidas pelo instalador, salvando o .quel em /quel/quelforge/pacotes/, pronto para distribuir com quel -i.

5Verificar Nix

Varre a pasta do Nix (.nix-portable), calcula o hash SHA-256 de cada arquivo e grava essa lista como base. Funciona do mesmo jeito da Verificar Sistema, mas focado só nos arquivos do Nix.

6Criar Quel com Nix

Deve ser usado depois de uma Verificar Nix. Compara a pasta do Nix com a base salva e compacta só os arquivos que não estavam lá antes em um pacote .quel, pronto para instalar depois com quel -i.

💡 O ideal é rodar a Verificar Nix logo após instalar o Nix pelo Quel, antes de instalar qualquer programa com ele. Se a pasta .nix-portable ainda não existir nesse momento, pode ser necessário criá-la manualmente antes de verificar.
📌 Programas empacotados pela Criar Quel com Nix dependem do Nix já estar instalado no sistema. Sem o Nix instalado antes, esses pacotes não funcionam.
💡 Todas as ações são feitas pela interface gráfica (yad), com barra de progresso e log de cada operação, no mesmo padrão visual do quel-gtk.
05 / instalação

Instale pelo QUEL

O Quelforge não vem instalado por padrão, é um pacote como outro qualquer do repositório. Abra o terminal como root e execute:

quel -d quelforge

Depois de instalado, abra a interface com:

quelforge
