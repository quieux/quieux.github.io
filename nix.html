01 / nix

Milhares de programas sem complicações

O Nix é um gerenciador de pacotes com um repositório enorme de programas prontos para instalar. Quando você não encontrar o que precisa no repositório oficial do Quieux, o Nix é a alternativa mais simples para resolver isso.

Como instalar Voltar ao repositório
02 / instalação

Instalando o Nix

Instale pelo QUEL

Abra o terminal como root e execute:

quel -d nix

Ou, se preferir, instale pela interface gráfica com o quel-gtk, buscando por "nix" na lista de pacotes.

03 / liberar permissões

Deixando o Nix pronto para uso

Depois de instalado, é preciso liberar a permissão do Nix uma única vez. É rápido, siga os passos abaixo:

1Entrar como root

No terminal, entre como root e informe a senha quando pedido:

su
2Liberar a permissão

Ainda como root, execute:

chmod 775 /bin/nix
3Sair do root

Digite exit para voltar ao seu usuário normal. Pronto, esse passo só precisa ser feito uma vez.

exit
04 / teste

Testando a instalação

1Instalar um pacote de teste

Com a permissão liberada, execute o comando abaixo para instalar o pacote hello como teste:

nix run nixpkgs#hello
2Verificar se está funcionando

Depois que a instalação terminar.

Se aparecer uma mensagem de saudação no terminal, o Nix está funcionando corretamente.

05 / pacotes proprietários

Instalando pacotes proprietários

Por padrão, o Nix bloqueia a instalação de programas com licença proprietária. Para liberar, use a variável NIXPKGS_ALLOW_UNFREE=1 junto com a flag --impure. Por exemplo, para instalar o Spotify:

NIXPKGS_ALLOW_UNFREE=1 nix run nixpkgs#spotify --impure

07 / problemas comuns

Problemas comuns

📌 Um erro comum é o horário do computador estar incorreto, isso causa falhas ao acessar os repositórios do Nix. Verifique se a data e a hora do sistema estão certas antes de reportar qualquer outro problema.
