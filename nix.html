01 / nix

Milhares de programas sem complicações

O Nix é um gerenciador de pacotes com um repositório enorme de programas prontos para instalar. Quando você não encontrar o que precisa no repositório oficial do Quieux, o Nix é a alternativa mais simples para resolver isso.

02 / instalação

Instalando o Nix

Instale pelo QUEL

Abra o terminal como root e execute:

quel -d nix

Ou, se preferir, instale pela interface gráfica com o quel-gtk, buscando por "nix" na lista de pacotes.

📌 O Nix só funciona corretamente após entrar como root no terminal. Use o comando su e informe a senha antes de executar qualquer comando do Nix.
03 / teste

Testando a instalação

1Instalar um pacote de teste

Como root, execute o comando abaixo para instalar um pacote simples de teste:

nix --extra-experimental-features 'nix-command flakes' profile add nixpkgs#hello
2Executar o pacote

Depois que a instalação terminar, execute:

hello

Se aparecer uma mensagem de saudação no terminal, o Nix está funcionando corretamente.

04 / configuração

Removendo a necessidade das flags

Reparou que o comando de teste precisa da flag --extra-experimental-features 'nix-command flakes'? Isso acontece porque os recursos nix-command e flakes ainda são experimentais e vêm desativados por padrão. Para não precisar digitar essa flag toda vez, ative os dois recursos permanentemente:

1Criar o arquivo de configuração

Como root, crie a pasta de configuração do Nix caso ela ainda não exista e edite o arquivo /etc/nix/nix.conf:

mkdir -p /etc/nix && nano /etc/nix/nix.conf
2Ativar os recursos

Adicione a linha abaixo no arquivo, salve e feche:

experimental-features = nix-command flakes

A partir daí, os comandos do Nix funcionam sem precisar da flag, por exemplo: nix profile add nixpkgs#hello.
